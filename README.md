# University Management System

A web-based university management system built with Angular, SpringBoot, PostegreSQL, Docker and AI-powered natural language search

---
The platform is designed to simplify the administration of academic institutions. 
The platform provides role-based access for administrators, professors, and students, enabling efficient management of courses, enrollments, grades, and users through a modern dashboard.

The platform has AI-power Natural Language Search, allowing users to interact with the system using everyday language
